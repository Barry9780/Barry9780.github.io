## LinkedIn

L’adresse `https://www.linkedin.com/feed/` est le fil d’actualité LinkedIn, pas l’adresse publique de votre profil. Le bouton LinkedIn reste donc marqué « profil à ajouter » jusqu’à ce que vous récupériez votre lien personnel (`https://www.linkedin.com/in/...`). Renseigner alors `linkedinUrl` dans `config.js`.
